# file locker

Шифрование и защита файлов паролем: GUI на tkinter

## Структура

```text
LICENSE
decrypt.py
main.py
output
send_password.py
sites.txt
```

## Установка

```bash
git clone https://github.com/Timmn3/file_locker.git
cd file_locker
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scriptsctivate
pip install -r requirements.txt
```

## Запуск

```bash
python3 main.py
```
